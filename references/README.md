# References

Real example jobs used to measure and check the app. **Nothing here is shown to customers.**
The app's proof template and production geometry were measured from the first job below, and the automated tests compare against it.

| File | What it is |
|---|---|
| `spec.txt` | The order specification text, as pasted into the app |
| `Edwin-J.docx` | The customer's wording |

| `Liquid Mercury.pdf` | The real customer proof ("Proof - 32241") that the proof template is measured from |
